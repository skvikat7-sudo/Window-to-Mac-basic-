# PROJECT CRYSTAL — Architecture & Technical Design

## 1. System Overview
Project Crystal is a native Windows 11 desktop environment built on **.NET 8**, **Direct3D 11**, **HLSL Shader Model 5.0**, **DirectComposition**, **Direct2D 1.1 / DirectWrite**, and **Windows Runtime / Win32 APIs**.

- **`ProjectCrystal.Rendering`** ([`LiquidGlass.hlsl`](../src/ProjectCrystal.Rendering/Shaders/LiquidGlass.hlsl), [`GpuDeviceContext.cs`](../src/ProjectCrystal.Rendering/Core/GpuDeviceContext.cs), [`LiquidGlassSurface.cs`](../src/ProjectCrystal.Rendering/Core/LiquidGlassSurface.cs), [`GlassWindowBase.cs`](../src/ProjectCrystal.Rendering/UI/GlassWindowBase.cs), [`CrystalUIHelpers.cs`](../src/ProjectCrystal.Rendering/UI/CrystalUIHelpers.cs), [`SpringAnimation.cs`](../src/ProjectCrystal.Rendering/Core/SpringAnimation.cs)):
  - Unified two-pass GPU rendering per surface:
    1. **Pass 1 (D3D11 HLSL Pixel Shader)**: Evaluates multi-shape analytic superellipse SDFs, computes a $C^1$-smooth 3D meniscus + convex dome surface normal field, performs Snell-inspired screen-space UV refraction & magnification against the live desktop texture, applies spectral R/G/B chromatic dispersion, controlled 9-tap Poisson optical diffusion, Schlick Fresnel edge reflections, internal rim bounce, and adaptive environmental luminance tinting into `DXGI_ALPHA_MODE_PREMULTIPLIED` buffers.
    2. **Pass 2 (Direct2D 1.1 + DirectWrite on the shared `IDXGISurface`)**: Draws crisp vector icons, app icons, spring-animated dock magnification, typography, sliders, toggles, and telemetry sparklines with zero synchronization lag.

## 2. Desktop Refraction Pipeline
1. Each glass overlay window sets `SetWindowDisplayAffinity(hwnd, WDA_EXCLUDEFROMCAPTURE)` when `CaptureBackend == LiveDesktopWgc`.
2. `WgcDesktopCaptureService` captures the active monitor via `Windows.Graphics.Capture` (`IsBorderRequired = false`, `IsCursorCaptureEnabled = false`) directly into a GPU `ID3D11Texture2D` without CPU readback.
3. Because DWM omits `WDA_EXCLUDEFROMCAPTURE` windows from WGC capture while keeping all underlying desktop wallpaper and native application windows intact, the HLSL shader samples genuine live desktop content behind the glass with zero self-capture feedback loop.
4. When idle (desktop pixels unchanged and no spring/hover animation running), `GlassWindowBase.TickAndRenderIfNeeded` skips redundant GPU passes (`PauseWhenIdle`), keeping idle CPU near zero.
